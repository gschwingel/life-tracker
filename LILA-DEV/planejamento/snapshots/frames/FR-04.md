COMPORTAMENTO ESPERADO
- Dado o app aberto / Quando o React monta / Então ao lado da tela principal aparece um drawer "Histórico — 7 dias" (desktop: fixo à direita, flex main + aside ~280px; mobile: gaveta oculta + botão "Histórico" que abre overlay), sem router e sem dependência nova.
- Dado qualquer dia dos últimos 7 (hoje-6 .. hoje) / Quando a lista renderiza / Então a ordem é descendente (hoje primeiro), cada linha mostra DD/MM/YYYY + chips resumidos (peso, treino ✓/·, cardio "tipo min", estudo ✓/·, aporte), e dia sem registro mostra "— sem registro —".
- Dado o clique numa linha / Quando carregarDia(dia) roda / Então o form principal é preenchido com os 3 SELECTs atuais (daily_logs + cardio_logs + invest_transactions) para aquele dia, o header vira "Editando DD/MM/YYYY" e aparece "Voltar para hoje".
- Dado diaEditando == hoje / Quando Salvar / Então o fluxo é o atual de FR-02, sem popup.
- Dado diaEditando != hoje / Quando Salvar / Então abre modal custom ("Salvar alterações em DD/MM/YYYY?" [Confirmar] [Cancelar]); Confirmar grava naquele dia (mesmos upserts/delete+insert de FR-02 com o dia como parâmetro) + persist(); Cancelar fecha sem gravar.
- Dado qualquer cálculo de data / Quando os 7 dias são derivados / Então a referência é local via toLocaleDateString('en-CA'); toISOString é proibido.
TESTE DE VALIDACAO
1. `npm run dev`, abrir a URL: drawer visível no desktop com 7 linhas, hoje no topo em DD/MM/YYYY.
2. Com registros em 2 dias distintos: linhas mostram chips resumidos corretos; dia sem registro mostra "— sem registro —".
3. Clicar num dia passado com dado: form preenche (peso/treino/cardio/estudo/aporte), header vira "Editando DD/MM/YYYY".
4. Editar dia passado + Salvar: modal custom abre; Cancelar não grava; Confirmar grava e o reload do dia mostra os novos valores.
5. Salvar o dia de hoje: sem modal, fluxo "Salvo ✓" 2 s inalterado.
6. Redimensionar para viewport mobile: drawer vira overlay atrás de botão "Histórico"; fechar volta ao form.
7. `npm run typecheck` + `npm run governanca:validar` + `npm run build`: exit 0 nos três.
